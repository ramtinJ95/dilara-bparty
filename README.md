# dilara-bparty

A web app with a live quiz and a photo contest for Dilara's 3rd birthday party.
Guests join on their phones by scanning a QR code; the host runs it from a
laptop.

Status: the foundation is built (joining, the live connection, the guest
shell and the admin view); the quiz and the photo contest are next. See
[docs/design.md](docs/design.md) for the quiz and photo contest, and
[docs/hosting.md](docs/hosting.md) for the Cloudflare plan.
